# DEQR Visual Identity & Design Tokens

## Brand Identity
DEQR features a modern, high-tech, sleek dark desktop interface inspired by AWKIT design aesthetics.

## Design Tokens (CSS Variables)

```css
:root {
  /* Color Palette */
  --deqr-bg-dark: #0f141c;
  --deqr-surface-card: #18202c;
  --deqr-surface-card-hover: #212c3d;
  --deqr-border: #2a384d;
  
  /* Accents */
  --deqr-accent-cyan: #00f2fe;
  --deqr-accent-blue: #4facfe;
  --deqr-gradient-primary: linear-gradient(135deg, #00f2fe 0%, #4facfe 100%);
  
  /* Status Colors */
  --deqr-status-success: #10b981;
  --deqr-status-warning: #f59e0b;
  --deqr-status-danger: #ef4444;
  
  /* Typography */
  --deqr-font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  
  /* Contrast */
  --deqr-text-primary: #f8fafc;
  --deqr-text-secondary: #94a3b8;
  --deqr-text-muted: #64748b;
}
```

> **Accuracy note.** The token block above is the original design intent and has
> drifted from what ships. The live tokens are `src/renderer/styles/theme.css`
> (desktop) and `mobile-web/src/styles.css` (receiver): the accent is
> `#0071e3` / `#2997ff`, and the type stack is the platform system font, not
> Inter. Read those files before changing interface colour.

## Theme Rules
- **Dark Mode**: Default primary theme.
- **Light Mode**: High-contrast light alternative for bright ambient scan environments.
- Contrast ratio minimum: 4.5:1 for standard text (WCAG 2.1 AA compliant).

## Application Icon System

The logo and every application icon live in [`branding/`](../../branding/README.md).
Full specification: [`branding/DEQR-BRAND-GUIDE.md`](../../branding/DEQR-BRAND-GUIDE.md).

- **Mark**: DEQR Vortex — five logarithmic-spiral arms converging on a focal
  emblem. One mark for both the Electron sender and the PWA receiver.
- **Palette**: built on the live product accent (`#0071e3` / `#2997ff`), not the
  `--deqr-accent-cyan` above, which appeared in the retired QR-block icon and in
  no shipped interface surface.
- **Masters**: `branding/source/*.svg`, generated by
  `scripts/brand/build-masters.mjs`.
- **Exports**: `npm run brand:masters && npm run brand:generate`. Every raster in
  `mobile-web/public/` and `branding/export/` is generated — do not hand-edit.
- **Consumers**: `build.win.icon` for Windows; the manifest, `<link>` tags and
  both application headers for the receiver.
