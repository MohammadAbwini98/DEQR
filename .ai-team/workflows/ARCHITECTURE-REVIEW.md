# Workflow: Architecture Review

## Execution Sequence

1. **Trigger**: IPC schema modifications, component boundary changes, or core stream engine updates.
2. **Analysis**: System Architect inspects contracts, data flow boundaries, and non-functional requirements (throughput, memory).
3. **ADR Recording**: Author Architecture Decision Record if fundamental pattern changes occur.
4. **Report Output**: Store review findings in `.ai-team/reports/architecture/`.
