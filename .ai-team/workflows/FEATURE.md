# Workflow: Feature Implementation

## Minimum Roles Involved
- **Project Manager** (Orchestration & Integration)
- **System Architect** (when IPC interfaces or component boundaries change)
- **UI/UX Designer & Branding Designer** (for user-facing screens)
- **Cybersecurity Engineer** (when trust boundaries or payload processing are affected)
- **Database Administrator** (when local storage schemas change)
- **Front-end / Back-end Engineers** (Implementation)
- **Quality Assurance Engineer** (Independent verification)

## Execution Sequence

```text
1. PM Intake & Scope Definition
2. Architecture / UI / Security Spec Review
3. PM Subtask Assignment (Owned Files Defined)
4. Implementer Execution & Local Tests
5. QA Verification Suite Execution
6. Security & Architecture Audit
7. Remediation (if gates fail)
8. Memory Update & Consolidated PM Report
```
