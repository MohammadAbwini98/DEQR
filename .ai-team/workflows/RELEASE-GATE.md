# Workflow: Release Gate Evaluation

```text
Release status: PASS | CONDITIONAL | FAIL

Scope assessed:
Implementation status:
Build status:
Automated test status:
Manual test status:
Security findings:
Architecture findings:
Database/migration status:
Known defects:
Deferred work:
Unverified items:
Residual risks:
Rollback readiness:
Recommendation:
Human decisions required:
```

## Non-Negotiable Rule
No agent may convert an unexecuted check into a pass. All evaluations require raw execution log evidence.
