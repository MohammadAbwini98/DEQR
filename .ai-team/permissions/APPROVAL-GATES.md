# System Approval Gates & Escalation Paths

## Gates Requiring Human Approval
1. Scope changes or material backlog reprioritization.
2. Destructive database actions or non-backward-compatible schema migrations.
3. Breaking public IPC or protocol changes.
4. Security risk waivers for High or Critical findings.
5. Installation of new NPM packages, MCP servers, or system software tools.

## Gates Managed by Project Manager
1. Subtask completion sign-off after QA & Security verification.
2. Merging feature implementations into main branch baseline.
3. Resolving inter-specialist recommendation conflicts.
